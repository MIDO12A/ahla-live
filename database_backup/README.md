## 📁 محتويات مجلد النسخة الاحتياطية (`database_backup/`)

| الملف / المجلد | الوصف |
| :--- | :--- |
| `complete_database_backup.json` | ملف تجميعي شامل وضخم (23+ ميغابايت) يحتوي على الـ 44 مجموعة والـ 17,409 مستنداً بالكامل في ملف واحد. |
| `collections/` | مجلد يحتوي على كل مجموعة مفصولة في ملف JSON مستقل لسهولة التعديل أو المعاينة المنفردة (مثل `users.json`, `rooms.json`, `gifts.json`, ...). |
| `media_backup/` | مجلد أرشيف الوسائط الكامل: تم تنزيل وحفظ جميع ملفات الميديا الـ 239 بالكامل (SVGA, VAP MP4s, إطارات, صور, بانرات) محلياً بدون أي روابط مفقودة. |
| `download_all_media.js` | سكربت تحميل وأرشفة كل ملفات الصور والأنيميشن من السحابة إلى جهازك. |
| `backup_metadata.json` | إحصائيات دقيقة بعدد المستندات لكل مجموعة ووقت التصدير. |
| `restore_database.js` | سكربت ذكي يقوم باستعادة ورفع النسخة الاحتياطية بالكامل لأي مشروع Firebase جديد تلقائياً وبأعلى سرعة مع الحفاظ على التواريخ وأنواع البيانات (Timestamps & GeoPoints). |
| `export_database.js` | سكربت إعادة أخذ نسخة جديدة لاحقاً في أي وقت. |
| `firestore.rules` | ملف قواعد الأمان والحماية الكامل لقاعدة بيانات Firestore. |
| `storage.rules` | ملف قواعد حماية رفع وتخزين الصور والملفات على Firebase Storage. |
| `supabase_schema.sql` | مخطط SQL لقواعد البيانات العلائقية (في حال رغبت بربط خدمة تعتمد على PostgreSQL/Supabase مستقبلاً). |

## 🚀 كيفية استعادة النسخة الاحتياطية وربط تطبيق جديد

### 1. استعادة البيانات إلى مشروع Firebase جديد
إذا أنشأت مشروع Firebase جديد وتريد نقل كل هذه البيانات والمجموعات إليه:
1. حمّل ملف مفتاح الخدمة `serviceAccountKey.json` الخاص بمشروعك الجديد من لوحة تحكم Firebase:
   - توجه إلى: `Firebase Console -> Project Settings -> Service Accounts -> Generate new private key`.
2. شغّل أمر الاستعادة التالي في موجه الأوامر:
```bash
node database_backup/restore_database.js "مسار/ملف/serviceAccountKey.json"
```
سيقوم السكربت تلقائياً بإنشاء الـ 44 مجموعة ورفع كافة المستندات والبيانات دفعة واحدة بدقة متناهية.

---

### 2. كيفية ربط تطبيق فلاتر جديد (Flutter Client)
لربط تطبيق Flutter جديد بهذه البيانات:
1. ضع ملف إعدادات Firebase داخل التطبيق:
   - أندرويد: `android/app/google-services.json`
   - آيفون: `ios/Runner/GoogleService-Info.plist`
2. تأكد من ضبط قواعد الحماية في Firebase Console عبر نسخ محتوى `firestore.rules` ولصقه في تبويب **Rules**.

---

### 3. كيفية ربط لوحة الإدارة (Admincore Dashboard)
لربط لوحة التحكم بالتطبيق الجديد:
1. افتح الملف: `admincore-dashboard/src/lib/firebase.ts`
2. استبدل كائن `firebaseConfig` بمعلومات مشروعك الجديد من لوحة تحكم Firebase.

---

### 4. كيفية ربط باك إند جديد (Node.js / Express Backend)
لربط سيرفر أو باك إند جديد:
1. ضع ملف `serviceAccountKey.json` داخل مجلد الباك إند.
2. في ملف `.env` الخاص بالسيرفر، حدد:
```env
PORT=4001
FIREBASE_PROJECT_ID=اسم_مشروعك_هنا
```
الباك إند سيتصل مباشرة بنفس الـ Collections وسيعمل بكفاءة كاملة فوراً.

## 📋 قائمة المجموعات والبيانات المحفوظة في النسخة الاحتياطية

1. **المستخدمين والحسابات:**
   - `users`: بيانات المستخدمين، المعرفات، الأسماء، الصور، الرتب.
   - `user_wallets`: المحافظ، رصيد الكوينز والماسات.
   - `user_stats`: إحصائيات المستخدمين ومستوياتهم.
   - `user_backpack`: حقيبة المستخدم (العناصر والمقتنيات المشتراة).
   - `admin_users` & `admin_action_logs`: حسابات الإدارة وسجلات المشرفين.

2. **الغرف والبث الصوتي:**
   - `rooms`: بيانات الغرف الحالية، الإعدادات، وأسماء الملاك.
   - `room_members`: أعضاء الغرف الحاليين.
   - `room_seats`: المايكات والمقاعد النشطة.
   - `room_messages`: رسائل الشات داخل الغرف (4,377 رسالة).

3. **الهدايا والمتجر والارتباط:**
   - `gifts` & `gift_categories`: قائمة الهدايا وفئاتها وأسعارها وتأثيراتها (SVGA).
   - `sent_gifts`: سجل الهدايا المرسلة (1,362 هدية).
   - `sent_lucky_gifts`: هدايا الحظ وصناديق الحظ (2,442 عملية).
   - `store_items`: متجر الإطارات، الدخوليات، والفقاعات.
   - `cp_couples` & `cp_requests` & `cp_settings`: نظام الكابلز والعلاقات ونقاط العشاق.

4. **الوكالات والوكلاء:**
   - `host_agencies`: وكالات المضيفين.
   - `host_agency_members`: أعضاء كل وكالة ومضيفيها.
   - `host_agency_join_requests`: طلبات الانضمام.
   - `agency_wallets`: محافظ أرباح الوكالات.
   - `agency_chat_messages`: شات الوكالات.
   - `agency_applications`: طلبات تأسيس الوكالات.
   - `agency_free_agents` & `agency_screenshot_reports`: تقارير الوكلاء الحرّة وإثباتات الدخل.

5. **الإعدادات والمستويات والتكوين:**
   - `app_config`: تكوين التطبيق وإعدادات النظام بالكامل.
   - `app_assets`: مسارات ملفات الجرافيكس والـ SVGA.
   - `level_config`: إعدادات مستويات الشحن ومستويات المضيفين.
   - `vip_config`: مميزات وباقات الـ VIP.
   - `signin_rewards`: جوائز تسجيل الدخول اليومي.
   - `tasks_config`: مهام التطبيق وجوائزها.
   - `banners`: البنرات الإعلانية في الصفحة الرئيسية.
   - `global_announcements` & `broadcasts`: الإعلانات والرسائل العامة.
   - `bug_reports`: تقارير وسجلات الأخطاء البرمجية (8,108 تقرير).
   - `notifications`: إشعارات المستخدمين.
   - `conversations` & `private_messages`: الرسائل الخاصة والمحادثات.
